# Matador Butcher Storefront

Premium Armenian-language storefront for Matador Butcher Shop. The site includes a meat catalogue, detailed product pages, branded Picnic Box collections for 2, 5 and 10 people, a restaurant-supply workflow, quality information, and request forms.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Online payment, fiscal receipt, and PEK integrations are intentionally outside the current scope. Cart submission creates a request-flow prototype and does not charge the customer.
